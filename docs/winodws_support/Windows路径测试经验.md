# Windows 路径测试经验

这份记录总结了我在 Windows 路径写入、读取和目录操作上的测试经验，主要用于验证 Hermes 的 Windows 适配是否已经正常。

## 测试目标

重点验证以下能力：

- 中文目录能否正确创建
- 中文文件名能否正确写入
- 带空格的路径是否可用
- 多层嵌套目录是否正常
- 文件覆盖写入、读取、重命名、删除是否稳定
- 路径是否会被错误写成字面字符串

## 测试过程

### 1. 中文目录与中文文件名

在以下目录下进行测试：

`D:\Doc\20260423宫崎葵`

测试结果：

- 目录存在
- 文件可以正常写入
- 文件内容可以读回
- 中文文件名没有问题

### 2. 带空格的中文路径

测试了类似这样的路径：

`D:\Doc\20260423宫崎葵\带 空格 的 子目录\空 格 测 试.md`

测试结果：

- 目录可创建
- 文件可写入
- 读取结果与写入内容一致

### 3. 多层嵌套目录

测试了三级嵌套路径：

`D:\Doc\20260423宫崎葵\第一级目录\第二级目录\第三级目录\深层测试文件.md`

测试结果：

- 多层目录创建成功
- 文件写入成功
- 读回内容一致
- 重命名成功

### 4. 覆盖写入与恢复

对已有文件做了覆盖写入，然后恢复原内容。

测试结果：

- 覆盖写入成功
- 读回内容正确
- 恢复原文件内容成功

### 5. 删除测试文件

测试过程中创建的临时文件和临时目录都成功清理。

测试结果：

- 文件删除成功
- 目录删除成功
- 没有残留测试产物

## 发现的问题

最早的问题不是权限，而是**路径映射/路径解析**：

- `D:\...` 路径曾经被错误当成普通字符串处理
- 结果文件落到了错误位置
- 经过修复后，写入链路恢复正常

## 结论

目前这套 Windows 路径处理已经支持：

- 中文目录
- 中文文件名
- 带空格路径
- 多层目录
- 写入 / 读取 / 覆盖 / 重命名 / 删除

这说明当前 Hermes 的 Windows 路径适配已经基本可用。

## 建议

后续如果再改相关代码，建议继续保留以下测试：

- 中文路径回读
- 带空格路径回读
- 深层目录创建
- 覆盖写入后恢复
- 删除临时文件与目录

这样可以及时发现 Windows 路径桥接是否再次退化。
