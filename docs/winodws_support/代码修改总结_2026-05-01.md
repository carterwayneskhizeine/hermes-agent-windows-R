## 冲突解决详情

### 1. hermes_cli/plugins_cmd.py（2 处冲突）

#### 冲突一：`cmd_install` 函数

**冲突原因：**
上游将 git clone 安装逻辑（包括 manifest 读取、路径消毒、manifest_version 检查、已有插件覆盖）提取为独立函数 `_install_plugin_core()`，并新增 `plugin.yml` 格式支持。我们的版本在 `subprocess.run` 中添加了 `encoding="utf-8", errors="replace"`（Windows UTF-8 编码修复）。

**解决方案：**
采用上游的重构（`_install_plugin_core` 函数 + `PluginOperationError` 异常体系），在上游的共享函数中补上 Windows UTF-8 编码修复：

```python
# _install_plugin_core 中的 subprocess 调用
result = subprocess.run(
    ["git", "clone", "--depth", "1", git_url, str(tmp_target)],
    capture_output=True,
    text=True,
    encoding="utf-8",
    errors="replace",
    timeout=60,
)
```

同时接受上游新增的 `plugin.yml` 格式支持：

```python
has_yaml = (target / "plugin.yaml").exists() or (target / "plugin.yml").exists()
```

#### 冲突二：`cmd_update` 函数

**冲突原因：**
上游将 git pull 逻辑提取为共享函数 `_git_pull_plugin_dir(target)`。我们的版本在 `subprocess.run` 中添加了 `encoding="utf-8", errors="replace"`。

**解决方案：**
采用上游的共享函数调用，在 `_git_pull_plugin_dir` 中补上 Windows UTF-8 编码修复：

```python
def _git_pull_plugin_dir(target: Path) -> tuple[bool, str]:
    try:
        result = subprocess.run(
            ["git", "pull", "--ff-only"],
            capture_output=True,
            text=True,
            encoding="utf-8",
            errors="replace",
            timeout=60,
            cwd=str(target),
        )
```

### 2. tui_gateway/server.py（1 处冲突）

**冲突原因：**
我们在 04-26/04-30 的修改中在 `_start_agent_build` 的 `_build()` 内添加了 `ephemeral` 检查（`if db is not None and not current.get("ephemeral"):`）和 `pending_title` 处理逻辑。上游引入了完整的 lazy session creation 机制（`c5b4c4816` — defer DB row until first message），在 `_build()` 中以注释替代 DB 创建逻辑：

```python
# Session DB row deferred to first run_conversation() call.
# pending_title applied post-first-message (see cli.exec handler).
```

**解决方案：**
采用上游方案。上游的 lazy session creation 在 `session.create` 时返回 `"lazy": True`，DB 行延迟到 `run_conversation()`（首次消息）才创建。这比我们的 `ephemeral` 检查更通用——所有 session 都延迟创建 DB 行，ephemeral session 从不发送消息则自然不会写入 DB。

我们的 `ephemeral` 检查和 `pending_title` 处理逻辑已被上游更完整的方案替代，无需额外补丁。
