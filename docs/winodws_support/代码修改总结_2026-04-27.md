## 冲突解决详情

### 1. hermes_cli/main.py

#### 冲突原因

上游在提交 `34eb1aaa`（`fix(update): use npm ci to stop rewriting package-lock on every update`）中将 npm 安装逻辑提取为新函数 `_run_npm_install_deterministic`，将原来的内联 `subprocess.run(["npm", "install", ...])` 替换为函数调用。

我们在 04-26 的修改对原内联调用添加了 `encoding="utf-8", errors="replace"`，与上游的重构产生冲突。

#### 解决方案

采用上游的 `_run_npm_install_deterministic` 重构（接受代码改进），同时在**函数定义内部**的两处 `subprocess.run` 都补上 Windows 所需的编码参数。

**修改位置：** `hermes_cli/main.py:5076-5094`（函数 `_run_npm_install_deterministic`）

```python
# 修改前（上游原始，缺少 encoding）
ci_result = subprocess.run(
    ci_cmd,
    cwd=cwd,
    capture_output=capture_output,
    text=True,
    check=False,
)
...
return subprocess.run(
    install_cmd,
    cwd=cwd,
    capture_output=capture_output,
    text=True,
    check=False,
)

# 修改后（添加 Windows 编码参数）
ci_result = subprocess.run(
    ci_cmd,
    cwd=cwd,
    capture_output=capture_output,
    text=True,
    encoding="utf-8", errors="replace",
    check=False,
)
...
return subprocess.run(
    install_cmd,
    cwd=cwd,
    capture_output=capture_output,
    text=True,
    encoding="utf-8", errors="replace",
    check=False,
)
```

**调用处冲突（`main.py:5843`）：** 使用上游版本（函数调用），丢弃旧的内联写法。

```python
# 最终结果（冲突位置）
result = _run_npm_install_deterministic(
    npm,
    path,
    extra_args=("--silent", "--no-fund", "--no-audit", "--progress=false"),
)
```

### 2. hermes_cli/web_server.py

#### 冲突原因

上游在提交 `625c31fc`（`fix(tui): run built TUI with production React by default`）中新增了 `env.setdefault("NODE_ENV", "production")`，确保 TUI 以生产模式的 React 运行。

我们在 04-26 的修改添加了 `env["HERMES_PYTHON"] = sys.executable`，确保 TUI 的 Node 子进程使用同一个 Python。两处修改在同一函数中相邻，产生冲突。

#### 解决方案

两处修改均有独立价值，全部保留，合并为：

**修改位置：** `hermes_cli/web_server.py:2331`

```python
# 最终结果（两处修改合并）
env.setdefault("NODE_ENV", "production")

# Ensure the TUI's Node child_process spawns the *same* Python that
# runs the dashboard.  Without this, the TUI may pick up a different
# Python from PATH or VIRTUAL_ENV (e.g. conda base) that lacks the
# tui_gateway module.
env["HERMES_PYTHON"] = sys.executable

if resume:
    env["HERMES_TUI_RESUME"] = resume
```
